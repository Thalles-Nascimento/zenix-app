# Zenix App

# Sobre
Muitas barbearias ainda sofrem com o processo manual de registro dos serviços prestados, dificultando a organização
financeira e até mesmo operacional, consequentemente o barbeiro sofre uma queda de produtividade. Pensando nisso que surgiu o Zenix App, um sistema feito para facilitar o registro dos atendimentos,
 persistir os dados e dar aos donos clareza financeira. Os barbeiros poderão anotar os atendimentos associados a ele,
tendo a clareza de quanto de fato eles estão faturando e os donos da barbearia poderão analisar os dados do mês
para se planejar para o mês seguinte, tendo acesso a relatórios de faturamento, serviços mais prestados, entre outros dados relevantes para o negócio.
