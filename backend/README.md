# Sistema Zenix

## Sobre
Muitas barbearias ainda sofrem com o processo manual de registro dos serviços prestados, dificultando a organização
financeira e até mesmo operacional, pois os registros são mais difíceis de serem guardados e o barbeiro sofre com a
sua produtividade. Pensando nisso que surgiu o Zenix, um sistema feito para facilitar o registro dos atendimentos,
 persistir os dados e dar aos donos clareza financeira. Os barbeiros poderão anotar os atendimentos associados a ele,
tendo a clareza de quanto de fato eles estão faturando e os donos da barbearia poderão analisar os dados do mês
para se planejar para o mês seguinte, saberá quanto faturou e quanto pagou, etc. O sistema também possui a 
funcionalidade de agendamento, permitindo aos clientes que agendem os seus horários e isso dê mais flexibilidade aos
barbeiros.
